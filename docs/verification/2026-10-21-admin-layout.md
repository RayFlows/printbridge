# 管理界面排版验证

日期：2026-10-21。范围仅为小程序管理页，服务端、身份权限和打印流程未变更。

## 界面调整

- 看板使用通栏分区，分别展示新打印开关、设备和未完成任务。
  统一内边距、文字层级与小号开关，设备名称可换行，队列和 USB 状态分行展示。
- 用户页使用已有 TDesign 搜索与列表布局，区分昵称、角色和编号。
  编号仅显示末八位，搜索仍匹配完整编号，操作仍使用完整编号。
- 用户行和任务行的操作按钮固定宽度，文字区域允许收缩及换行。
  空列表使用 TDesign 空状态，项目自身尺寸继续使用 rpx 和底部安全区。
- 搜索和开关的 change 事件在对应控件处理，页签只接受合法名称，
  避免嵌套输入事件导致页签跳转。
