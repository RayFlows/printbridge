# 黑白预览验证

日期：2026-10-22。

## 复现与原因

使用合成三页 PDF、真实 Poppler、临时 SQLite/文件目录和模拟打印后端，
从 `printing.Prepare` 和 `printing.Preview` 贯通复现黑白设置仍返回彩色图片。
修复前，黑白、自动黑白及其旧缓存场景均检测到 36,786 个彩色像素。

原因是计划已保存颜色模式，CUPS 也接收 `print-color-mode`，
但预览调用只传入 PDF、页码和图片路径，没有颜色模式。
客户端修改颜色后会准备新计划并下载对应图片，不是此次根因。

## 修正

- 打印预览将计划颜色模式传给 Poppler；黑白、自动黑白使用灰度渲染。
  彩色、自动及缺省模式保留原色。原始文档预览仍保持原色。
- 新缓存名绕过旧彩色 PNG，使已存在的黑白计划也能正确生成预览。
  重复读取继续复用正确缓存，原目录保留期限和清理逻辑不变。
- 不改写上传文件或已准备的 PDF，不改变 CUPS 颜色参数、驱动、队列或设备配置。
  API 和数据库结构不变，无迁移。

## 剩余验收

手机实际页面仍需用户复测；已打开页面中的本地图片不会因服务升级主动替换，
切换一次颜色模式或重新进入设置页后重新下载即可。

本轮未提交实体打印，不将预览灰度等同于打印机准确色彩或墨水配比的模拟。
自动和缺省模式的最终颜色由现有驱动决定，预览保留原色。
