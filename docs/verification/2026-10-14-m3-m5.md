# M3-M5 文档输入与打印流程验证

日期：2026-10-14。服务构建版本：`0.3.0-dev`。

本文记录 M3-M5 初始验收；同日后续的选项扩展和微信模拟器界面验收见
[移动端修正验证](2026-10-14-mobile-options.md)，其中更新了下文的模拟器待验收项。

## 已执行

- Go `gofmt`、`go vet ./...`、`go test -race ./...` 通过。
  工具检查另显式开启 `PRINTBRIDGE_TEST_POPPLER=1` 和 `PRINTBRIDGE_TEST_OFFICE`，
  真实 Office 检查实际执行，非仅跳过。最终图片导入改为保留原生比例后重跑图片与 EXIF 检查。
- Windows 二进制与 Linux ARM64 交叉编译通过。ARM64 结果仅为构建证据。
- 客户端类型检查和 59 项测试通过，使用模拟 wx；五个页面及全局样式通过官方工具附带的
  WXML/WXSS 离线编译。自有页面尺寸检查确保使用 rpx，未修改 TDesign 内部样式。
- SQLite schema 1→2 保留文档、重复打开、拒绝未来版本、打印快照、唯一幂等键、
  会话跨重启有效、撤销持久化及访问码轮换撤销旧会话通过。
- 真实工具：LibreOffice 26.8.1、Poppler 26.07.0。Office 来自官方 Windows 安装包，
  The Document Foundation 签名有效，仅解包到被忽略的项目工具目录。
- DOCX/DOC（2 页）、XLSX/XLS（1 页）、PPTX/PPT（2 页）、ODT（2 页）、ODS（1 页）、
  ODP（2 页）、RTF/TXT/CSV（各 1 页）逐一转换、读取页数、渲染首面和独立验证 PDF 通过。
  所有文件为仓库合成夹具，不包含用户文档。
- JPG、PNG、WebP、BMP、GIF 转换为 1 页，TIFF 夹具保留 2 页。
  EXIF 6 的 JPEG 使用真实渲染结果检查颜色区域的旋转方向。
- 真实 PDF 布局检查使用独立 `pdftotext` 核对 3→1→2 的重排、
  第 4 面空白、正反阶段复制顺序、背面旋转、2/4/6/9/16 合一及缩放。
- 纯业务测试覆盖 1/2/3/16/17 页正反对应、非连续范围、奇偶仅筛选一次、
  倒序、多份、补空白、能力拒绝、未确认校准、所有权、重复创建和失败清理。
- 模拟 IPP 验证 held Create-Job→Send-Document→Release-Job，
  copies=1、number-up=1、page-set=all、正常输出顺序，使用 IPP URI 和 PDF 文档格式，
  不重复附加原页范围。替换/忽略参数的成功响应会停止并取消空任务，不继续发送。
- 恢复测试覆盖创建响应丢失、发送成功但响应丢失、发送结果无法确认、释放响应丢失、
  非 indefinite hold、等待翻纸阻止本程序后续任务、服务重建、重复继续及取消。
  无法确认的发送不会被自动重发。
- 完整 HTTP 集成使用真实 SQLite/PDF/IPP 适配器和本机虚拟调度器：
  授权→上传三页文档→四面排版含空白→预览→幂等提交→等待翻纸→关闭并重建服务→
  沿用持久化会话→确认翻纸→完成。虚拟调度器只收到两个阶段作业及各一个 PDF，
  文档字节只保存在测试内存中，从不接触物理打印机。

## 本地试用服务

已备份旧本地数据目录，并更新到 schema 2 和 `0.3.0-dev`。
保留私有“本地调试（自动授权）”启动项，继续使用同一服务地址。
服务在开发电脑上运行，通过既有隧道读取树莓派 CUPS。

通过实际 HTTP 服务上传 DOCX、XLSX、PPTX、JPEG 和两页 TIFF，
逐一下载原始页面与基于真实队列报告的 A4 能力生成的最终排版预览。
返回页数分别为 2、1、2、1、2。已视检 Word 的中文段落、Excel 表格、
PPT 中文标题和照片内容；纵向排版会按布局规则旋转横向内容以适配纸面。
测试会话没有创建任何打印任务，结束时撤销测试授权。
原文件与布局 PNG 仅保留在被忽略的本地测试目录。
