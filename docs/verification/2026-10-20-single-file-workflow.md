# 单文件流程验证

日期：2026-10-20

## 缺陷与修正

修改前运行导航回归测试，首次上传得到
`printers → document → settings`，而非预期的 `printers → settings`；
重新上传也跳离当前设置页。旧测试只断言跳转地址，没有模拟完整导航栈。

现在选择页仅选文件和上传，成功后替换为设置页。唯一预览及确认打印均在设置页，
“重新上传”在原页完成选取和上传，成功后更换当前文件并恢复全部默认打印参数。

## 已验证

- TypeScript 编译及全部 93 项客户端测试通过。
- 真实页面处理器、服务层及模拟 `wx` 导航栈：首次上传只留下打印机列表与设置页；
  连续重新上传 12 次保持同一设置页，返回直接到打印机列表。
- 初次选择和重试的重复点击不重复上传或跳转；跳转失败只重试打开设置，
  不再次上传已成功的文档，也不下载冗余的原稿预览。
- 取消来源选择、取消文件选择、读取失败和替换上传失败保留旧文档及可用预览；
  新文件成功上传后恢复默认参数，重置页码、份数、奇偶和文档效果。
- 旧文档的准备请求和分页下载晚返回时不覆盖新文档，也不污染其计划替换链；
  旧临时图片清理，新预览保留。
- 新文档预览准备失败后可单独重试，不重复上传；选取/上传期间禁止修改参数和打印。
- 选择/上传期间离开页面忽略晚返回结果，中止正在上传的任务；授权失效回到扫码入口。
- 整个文件流程不调用 `/jobs`；自动检查没有访问真实打印设备。
- 微信离线 `wcc` / `wcsc` 编译选择页与设置页的 WXML/WXSS 成功。
- `server/` 的 `go vet ./...`、`go test -race ./...` 通过。
