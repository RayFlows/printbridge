## 复现及原因

初始只读检查显示：

```text
printer-state = stopped
printer-state-reasons = paused
printer-state-message = Unplugged or turned off
printer-is-accepting-jobs = true
```

系统 USB 枚举没有目标设备。原客户端只映射 state 和 reasons，
没有请求详细消息，也没有独立读取设备连接；因此界面只显示“已暂停”。
自动回归先复现 `已暂停 != 设备未连接`，修正后通过。

目前 API 同时返回 `state=stopped`、`deviceState=disconnected`；
使用实际响应运行客户端解析/展示得到：

```text
设备未连接
USB 未连接（关机或拔线）
队列已暂停
未检测到 USB 设备，请检查电源和连接线；队列暂停
```

无法区分关机、断电或拔线；连接状态也不证明纸张、墨水及机械状态就绪。
没有通过恢复队列来伪装设备已在线。
