# cups-web 功能对照

核对日期：2026-10-14。参考固定提交
`hanxi/cups-web@b2a3082b635b7fd2abd0e5efadfdd69609200e52` 的
[`PrintOptions.vue`](https://github.com/hanxi/cups-web/blob/b2a3082b635b7fd2abd0e5efadfdd69609200e52/frontend/src/components/print/PrintOptions.vue)。
它有选项不等于 PrintBridge 已经实现，界面标签相同也不代表实际输出相同。
本次按行为独立实现，没有复制该组件代码。

| 打印选项 | cups-web 参考版本 | PrintBridge 当前实现 |
| --- | --- | --- |
| 颜色、份数、单双面 | 有 | 有；自动双面取决于设备，另有手动双面阶段 |
| 纸张大小 | 固定选项列表 | 根据设备报告的纸张生成 |
| 纸张类型 | 普通纸、照片纸等固定列表 | 根据 IPP 报告；未知时只保留队列默认 |
| 进纸盒 | 根据设备报告 | 根据设备报告；提交原始 IPP 关键字 |
| 缩放 | 自动、自动适应、适应、填满、无缩放、自定义 | 适应、仅缩小、填满、实际大小、自定义；没有重复的自动模式 |
| 自定义缩放 | 10–400% | 10–400%，相对于原稿大小，先按小页裁切再拼版 |
| 页码范围 | 有 | 有，逗号分隔，如 `1-5,8` |
| 奇数、偶数、偶数倒序 | 有 | 奇偶选页只执行一次；默认按整张纸倒序，保留双面配对及拼版小页顺序 |
| 每张/每面页数 | 1/2/4/6/9/16 | 1/2/4/6/9/16 |
| 拼版顺序 | 四种 | 四种，已真实渲染检查小页位置 |
| 小页边框 | 有 | 有，预览与提交使用同一 PDF |
| 水平镜像 | 有 | 有；整面拼版及水印一起镜像，预览和打印同源 |
| 水印文字 | 有 | 有；单行 80 字，中文需要可用字体；缺少字形明确报错 |
| 图片黑白反转 | 黑白图片条件下可选 | 有；图片原稿反色，彩色可用，纸边及补空白保持白色 |

2026-10-20 补齐以上三项打印效果；自动检查使用实际 PDF 和虚拟 IPP，
实体出纸与手机检查另行记录。

参考项目另有 `IdCardUpload.vue`、`ImageCropModal.vue`，PrintBridge 当前没有身份证专用
排版和图片裁剪编辑器。它们属于后续文档编辑增量，不能用普通图片上传替代这些功能的验收。

两者也不是同一个产品界面：PrintBridge 的目标是微信选文件、授权预览、
持久化打印任务与手动翻纸确认。以上表格只核对当前打印选项，不声称覆盖参考项目全部功能。
