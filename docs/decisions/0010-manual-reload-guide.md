# ADR 0010：设备翻纸配置与普通用户引导

日期：2026-10-19

## 背景

首轮纸面、第二轮顺序、额外旋转及“已校准”不是每次打印的用户选择。
此前本机缓存允许不同手机为同一设备设置不同纸路，且短边提示同时改变物理翻纸
动作和软件旋转，难以验证。用户要求直接展示放纸示意，并保留实际可实现的短边装订。

## 决定

- 部署者通过 `PRINTBRIDGE_MANUAL_DUPLEX_PROFILES` 按队列配置带版本的方案。
  `printing` 的后端包装仅为列表补充该信息，不修改 CUPS；不通过队列名称猜测型号。
- 第一个方案为 `rear-face-up-v1`：偶数面先印、第二轮同序；物理动作固定为沿纸张
  长边左右翻面，空白面朝向使用者，原先先出纸的短边先装入后纸盘。
  新设置仍默认整张纸倒序，保留原有正序选项。
- 客户端请求携带可选 `manualDuplexProfile`。服务端核对其属于当前队列，并统一解析
  首轮、顺序、旋转和旧 `calibrated` 字段，保存完整任务快照。客户端不计算页序或角度。
- 同一放纸动作下，纵向长边第二轮旋转 0°、纵向短边 180°；
  横向长边 180°、横向短边 0°。这是 PDF 旋转，CUPS 仍接收单面任务。
- 小程序去掉所有校准控件和本机校准缓存读取，保留单双面/装订边与实际翻纸完成确认。
  两个页面共用三步图示。未配置或不认识的方案不显示手动双面选项，不套用本机默认值。
- 旧接口不传方案时仍使用明确校准参数；旧任务仍用原快照，客户端给出中性提示，
  不用新图示替换未知的旧纸路。

## 证据与边界

佳能 G2010 系列手册首页列出 G2810；其手动双面说明允许选择装订边。
装纸说明要求打印面朝上、纸张竖向装入。它没有公开提供与本项目页序相同的第二轮
放纸弹窗，因此不能把厂商说明当成当前组合的实体出纸验收。

- [系列及型号](https://ij.manual.canon/ij/webmanual/Manual/All/G2010%20series/EN/CNT/Top.html)
- [手动双面](https://ij.manual.canon/ij/webmanual/PrinterDriver/W/G2010%20series/1.0/EN/PPG/dg-c_duplex.html)
- [装纸](https://ij.manual.canon/ij/webmanual/Manual/All/G2010%20series/EN/UG/ug_l_01_04_c.html)

图示由本项目独立绘制，不复制佳能图片。方案结合用户已描述的纸路，仍需实体确认。
虚拟设备验证页序、空白、旋转与恢复，不验证机械进纸方向和最后纸叠朝向。

## 兼容和回退

仅增加可选 API 字段，SQLite schema 仍为 2。`calibrated=true` 对配置方案表示已按
部署配置解析，不是自动测量。旧 API 参数和已保存阶段文件不变。
新版客户端依赖服务端方案字段；须先升级服务端再编译客户端。回退到不认识该字段
的服务端时须同时回退客户端；不能让旧服务端继续处理包含新方案的未完成任务。
配置改变前先完成活动任务，按部署说明备份完整数据和配置。
