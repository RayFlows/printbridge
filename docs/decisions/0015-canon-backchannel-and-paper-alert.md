# ADR 0015：佳能回传适配与缺纸弹窗

日期：2026-10-21

## 原因

G2810 的 USB 回传已有 `GetStatusResponse / OK / stopped / MediaEmpty`，
但当前 Gutenprint 没有读取该管道并上报 CUPS，页面只能看到图像处理百分比。
常驻“如果中途缺纸”提示不能替代实际缺纸提醒。

## 决定

- 增加可选的 `printbridge-canon-monitor`，由 CUPS 作为 port monitor 启动。
  保留 Gutenprint 和 USB 后端；stdin 到 stdout 原样转发，不处理页序、不提交或恢复作业。
- 独立的 `canonstatus` 解析 FD 3 中的 IVEC XML，通过 stderr 的
  `STATE: +media-empty-error` / `STATE: -media-empty-error` 报告标准状态。
  应用服务继续读取 IPP，不获得 root 权限或直接接触 USB。
- 完整、成功的 `stopped / MediaEmpty` 报文触发缺纸；明确的 `idle` 或
  `processing` 且 `status_detail` 存在并为空时清除。截断、失败、未知和其他故障不表示恢复。
  支持任意分片、连续报文、杂字节后的重新同步，限制帧长、字段长度和 XML 深度。
- 输出数据转发和状态读取并行。stdin EOF 后关闭 stdout，让后端能够结束，
  但继续监听状态，直到后端关闭回传或取消。EOF 后连续 60 秒没有有效状态时退出监听；
  有效的重复报文也延长监听，缺纸等待不会因总时长到期而中断。
  退出监听不清除未知或未恢复的缺纸原因。
- 小程序任务页复用打印机查询接口。只在当前可见页面、本任务正在打印且对应设备未断开、
  队列明确报告缺纸时弹窗。同一次未恢复的缺纸只提醒一次；请求失败、未知和断开不重置提醒。
  关闭弹窗只表示已读。取消确认与缺纸弹窗不重叠；翻纸接口仍只用于 `awaiting_flip`。
  删除常驻“如果中途缺纸”内容，保留已有一般状态说明和实际翻纸引导。

## 安装与兼容

HTTP 契约、数据库和任务参数不变。旧部署不安装此适配器仍保持原有能力，
不能因此声称所有设备都能上报缺纸；只有已报告标准缺纸状态的队列才弹窗。
适配器仅针对本次 G2810 IVEC 字段验证，不推定其他佳能机型兼容、墨量或机械状态可读。

安装器须显式运行，默认用户服务安装不会修改 CUPS。
拒绝有未完成作业或仍在处理、状态未知的队列；取消后作业退出列表不等于后端已退出。
空闲时暂时拒收新任务并再次核对，然后备份 PPD 和原监视器。
先上传 PPD 声明，再连同该 PPD 选择监视器，使 CUPS 验证新声明并刷新能力缓存。
二进制按内容摘要命名，不覆盖另一队列可能正在使用的版本。
失败时尝试恢复原 PPD、监视器及接收状态。回退同样检查任务和配置变化，
不覆盖安装后另行修改的 PPD；共享的旧二进制留待管理员核对后回收。

PrintBridge 每个阶段提交单文档，正常由后端关闭回传结束监听。
其他客户端的多文档作业在文件间可能保留回传写端，存在至多 60 秒静默等待；
本轮没有宣称该路径已与实体设备验收。适配器不提供作业外持续遥测，
也不把 CUPS 完成或 XML `idle` 当成已经核对纸叠、墨量或真实完成的证明。

## 来源与验证

使用 CUPS v2.4.10 的公开过滤/后端接口及 PPD port monitor 声明，
结合现场已验证的协议字段独立实现，没有提取或翻译第三方驱动代码。
协议来源见先前调查记录；单元、独立管道和隔离 CUPS 的证据见
[缺纸适配验证](../verification/2026-10-21-paper-out-adapter.md)。
生产启用与实体缺纸恢复必须单独记录，不能由虚拟报文验收替代。
