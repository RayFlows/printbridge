# ADR 0018：自填称谓与浮动底栏

日期：2026-10-21。状态：本地及微信模拟器验证完成，手机触控待验收。

## 决定

用户自填资料明确称为“称谓或昵称（选填）”，供显示和管理员识别，不要求真实姓名，
不调用微信昵称接口。保留 `name` API 字段、数据库字段、已有值和保存/清空行为，
无需迁移或服务端部署。个人页、管理页和错误提示使用一致的称呼。
这更新 ADR 0016 / 0017 中的姓名语义，不改变隐私声明应反映实际处理内容的要求。

采用微信 `custom-tab-bar` 组件渲染固定在底部安全区之上的胶囊导航，
图标和文字共同呈现“打印 / 我的”，胶囊内的选中滑块支持点击及横向拖动。
页面仍为已注册的两个 tab，通过 `wx.switchTab` 切换，保留微信页面缓存和返回语义。
两个页面在 `onShow` 通过 `getTabBar` 明确同步各自的选中项，不从组件显示时仍可能
滞后的全局路由栈推测所属页面，不维护独立的页面状态。
拖动释放才切页，取消、多指、竖向手势不切页；切换失败恢复当前选中项。
两页为浮动底栏保留内容空间，其余页面继续使用原有操作区。

图标取自固定版本 `tdesign-icons-svg@0.4.5`，保留 SVG 原稿和 MIT 许可，
生成本地 PNG 随包分发，避免导航依赖远程字体。未复制上游 tabBar 业务代码。
其他页面继续使用已有 TDesign 组件。

依据：微信官方“自定义 tabBar”文档：
`https://developers.weixin.qq.com/miniprogram/dev/framework/ability/custom-tabbar.html`。

## 验证边界

客户端检查覆盖实际路由同步、点击、拖动、取消、切换失败和迟到回调。
WXML/WXSS 编译、微信模拟器和手机触控分别记录，模拟事件不等于手机验收。

TypeScript、143 项客户端测试、相关 WXML/WXSS 官方离线编译、Go vet/race 通过。
微信模拟器在 320×568 和 390×844 两种机型检查个人页、打印页及底部留白；
点击及双向拖动切换通过。模拟器曾复现返回缓存页时选中项滞后的问题，
改为页面 `onShow` 同步后通过，并以过期全局路由状态补充回归检查。
未提交实体打印，也未在手机上验收触控手感及安全区表现。
