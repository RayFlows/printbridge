# ADR 0019：以扫码切换取代独立退出

日期：2026-10-21。状态：本地、正式配置及微信模拟器读取验证完成；手机待验收。

## 决定

删除“我的”中的“退出当前打印服务”和离线退出入口，以及仅供退出使用的页面状态和处理代码。
普通用户从打印码进入，后续重入复用有效会话；打印页继续提供扫码更换。
新连接成功后再替换、撤销旧会话，取消扫码保留旧连接，失败不预先清除原会话。
此决定取代 ADR 0017 中“退出仅保留在我的”的界面约定。

保留服务端会话撤销接口及客户端会话服务，供切换、迟到授权清理和兼容已有调用。
不改变 API、数据模型、已保存的称谓或任务归属。
管理员继续由私有服务配置指定内部用户编号，不能用本地角色标记授予权限。

## 验证

检查个人页不再提供退出，保存称谓时仍防止重复提交，打印页扫码入口保留当前连接，
以及服务端确认管理员后才开放管理入口。TypeScript、144 项客户端测试、
个人页 WXML/WXSS 官方离线编译及 Go vet/race 通过。
当前账号经私有服务配置指定为管理员后，既有会话在微信模拟器读取到管理入口、
真实设备看板与用户列表；没有调用管理写操作或提交打印。
配置备份与现场证据见 [管理员启用记录](../verification/2026-10-21-admin-activation.md)。
