# ADR 0009：手动双面的首轮纸面

日期：2026-10-19

## 原因

用户实测三页文档得到第一轮 3、1，第二轮空白、2。此前整张纸倒序保证配对，
但固定先打印奇数面，未满足最终第 1 页朝上的要求。该进出纸及翻纸方式需要
先输出空白、2，再输出 3、1。只切换倒序开关不能改变两轮先后。

## 决定

- 新增可选设置 `manualFirstSide`，`front` 为奇数面先印，`back` 为偶数面先印。
  小程序新设置默认 `back`，继续默认整张纸倒序和第二轮同序。
  奇偶指拼版及补白后的纸面，不再筛选原稿页码。
- `printing.Settings` 统一决定第一、第二阶段；任务 phase 仍表示逻辑正反面，
  不是第几轮。第一轮完成后等待翻纸，确认后进入第二轮，第二轮完成才结束任务。
- `backOrder` 和 `backRotation` 用于第二轮，短边翻转也在第二轮增加 180 度旋转。
  旧的奇数面先印配置保持原有语义。空白面必须保留，以维持两轮纸张数量及配对。
- 状态提示明确奇偶面与轮次。首轮、第二轮顺序或额外旋转改变时需重新确认校准。
  校准缓存改为 v2，包含首轮纸面；不自动把旧 v1 校准当作新顺序已验证。

## 兼容及回退

字段缺省或空字符串保持旧的奇数面先印，已有计划、阶段 PDF 和任务不重写。
JSON 快照包含新字段，无 SQL 变更，schema 仍为 2。
重启恢复与重复继续均按保存的设置处理。单面及自动双面不使用首轮设置。

须先升级服务端再使用新客户端。旧服务端无法正确恢复偶数面先印的活动任务；
回退前必须完成或取消这些任务，保留整个数据目录，不能只因 schema 相同就降级。
恢复升级前备份仍须核对其后是否已有打印副作用，不能重发已完成阶段。

## 验证边界

模拟打印验证 1/2/3/4/16/17 页、补白、多份、拼版及非连续范围，
覆盖第一轮等待、重启、重复确认、取消以及第二轮旋转。
真实 PDF 与虚拟 IPP 检查实际发送的内容；实体纸张朝向及装订结果仍需用户实测。
