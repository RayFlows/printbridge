# ADR 0011：文档效果与设备连接状态

日期：2026-10-20

## 文档效果

增加可选的 `mirror`、`watermark` 和 `invertImages`。旧请求缺省均不启用，
旧计划及任务的 PDF 不重算，SQLite schema 仍为 2。

`printing` 校验参数及输入类型，`pdf` 执行效果。图片反色仅允许原始图片格式，
在选页后、缩放和拼版前以 PDF Difference 混合处理原图画布；不反转纸边。
文字水印位于完成拼版的纸面中央；随后水平镜像整个纸面，最后才补双面空白。
第二轮旋转和整张纸倒序仍走现有流程。预览和阶段打印引用同一不可变结果，
不向 CUPS 再发送镜像、水印、反色或页码筛选选项。

水印文字限 80 个 Unicode 码点、单行，不接受控制字符。使用已锁定的 x/image
读取系统字体并生成透明文字图，pdfcpu 将其作为图像水印嵌入 PDF；不注册可变全局字体。
可用 `PRINTBRIDGE_WATERMARK_FONT` 指定 TTF/OTF/TTC，默认探测 Noto CJK、微软雅黑、
PingFang 的系统安装位置；没有时仅以 Go Regular 兜底。缺失字形或显式字体错误返回
`422 watermark_font_unavailable`，不输出方框或假成功。系统字体不随仓库分发。

## 状态来源

此前只展示 IPP `printer-state=stopped`，漏掉了 `printer-state-message`，
用户关机时看到笼统的“已暂停”。队列状态可能保留上次错误，不能推断当前电源。

保留原有队列字段，新增可选 `stateMessage` 和 `deviceState`。Linux 且 CUPS 地址为
localhost/127.0.0.1/::1 时，读取 sysfs，用内部 USB URI 的序列号和厂家识别当前设备。
不打开 USB、不调用探测后端、不发打印数据、不返回设备 URI 或序列号。
远程 CUPS、其他系统、身份缺失、读权限失败均返回 unknown。

客户端分别显示 USB 连接、队列状态和接收状态。设备缺席优先显示“设备未连接”，
不能区分关机、拔线或断电；USB 已连接也不能证明纸张、墨水或机械状态就绪。
已连接时不把队列历史断线消息当成当前离线；未检测时明确为队列上次报告。
页面可见时每 5 秒刷新，隐藏或退出停止；刷新失败显示错误，不伪造实时状态。

不自动恢复暂停队列，不修改电源设置。电源管理属于厂商维护能力，尚未接入通用 API。
