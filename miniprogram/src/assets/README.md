# Paper Reload Artwork

`reload-collect.svg`, `reload-turn.svg` and `reload-insert.svg` are original
PrintBridge diagrams, licensed under the repository's MIT license.
The corresponding transparent PNGs are rasterized at 800 x 800 from the
200 x 200 SVG viewboxes. The mini-program uses PNGs; SVGs remain the editable
source. Regenerate the matching PNG when changing a diagram.

Pink identifies the same physical short edge across all three steps.
Green marks printed content; white marks the unprinted side. These diagrams
apply only to the `rear-face-up-v1` handling profile. They are not Canon artwork
or evidence of physical calibration. See ADR 0010 for sources and assumptions.
